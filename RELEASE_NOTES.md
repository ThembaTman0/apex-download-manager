Press Ctrl+K to do anything in Apex from the keyboard.

**New**

- Command palette: press Ctrl+K (or click Commands in the Downloads toolbar) and type. Run an action such as Add URL, Grab Video, Pause all or Retry failed, jump to any Settings page, or type part of a file name to open that download's Properties. It only offers what applies right now, and anything you type can also be searched for in Settings.

**Fixes**

- A fresh install now opens with the welcome tour. If an older Apex had been used on the same Windows account, a new install or a portable copy could show an old version's "What's new" instead.
